Place your room images here using one folder per room type.

Example layout:

- single/room-1.jpg
- single/room-2.jpg
- double/room-1.jpg
- deluxe/room-1.jpg
- suite/room-1.jpg
- twin/room-1.jpg

The seeder will read the images from these folders and apply the first image as the room main image, then the rest as gallery images.

Supported formats: jpg, jpeg, png, gif, webp
